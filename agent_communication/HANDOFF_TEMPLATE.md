# Handoff And Status Templates

Copy the relevant template into `agent_communication/TASK_LOG.md`.

## Status Update Template

```markdown
## Status Update
- Agent:
- Task ID:
- Timestamp:
- Current state:
- Completed:
- In progress:
- Blockers:
- Files touched:
- Commands/tests run:
- Next step:
```

## AI Handoff Template

```markdown
## AI Handoff
- From:
- To:
- Task ID:

- Important context:
- Commands/tests run:

- Known issues:
- Open questions:
- Requested next action:
```

## Review Finding Template

```markdown
## Review Finding
- Severity: Blocker | High | Medium | Low
- File/area:
- Issue:
- Why it matters:
- Evidence:
- Suggested fix:
```
