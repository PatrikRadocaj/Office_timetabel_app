# Claude Project Instructions

This project uses the shared Codex + Claude collaboration workflow.

Start every session by reading:

1. `agent_communication/COLLABORATION_PROTOCOL.md`
2. `agent_communication/PROJECT_DOCS.md`
3. `agent_communication/TASK_LOG.md`

Use `agent_communication/HANDOFF_TEMPLATE.md` for structured updates to Codex or the user.

Do not create a separate Claude-only source of truth. If project facts, decisions, tasks, or user-facing behavior change, update the shared files under `agent_communication/`.
